# 🌿 리무브 체형교정 네이버 블로그 자동화 시스템 (blog-auto)

> **"불편함을 Remove, 내 몸을 Re-move"**  
> 경기 구리시 갈매동에 위치한 **리무브 체형교정**의 네이버 블로그 콘텐츠 기획, 마크다운 작성, 그리고 네이버 스마트에디터 ONE 자동 임시저장 파이프라인입니다.

---

## ✨ 핵심 기능

1. **지능형 블로그 포스팅 기획 & 작성 (`.agents/skills/naver-blog`)**
   - 물리치료사 출신 체형교정 전문가의 솔직 담백한 시선과 4단계 교정 철학(근육 ➔ 신경 ➔ 관절 ➔ 운동재교육) 적용
   - 모바일 최적화 가독성 및 친근한 톤앤매너
   - **의료법 준수 원칙**: 비의료기관 기준에 맞추어 '치료' 대신 '교정/케어/재활운동' 표준 용어 엄격 적용
   - **원장 실명 보호 (SEO 최적화)**: 검색 엔진 텍스트 인덱싱 방지를 위해 실명 및 프로필을 고화질 이미지 카드로 제공

2. **스마트에디터 ONE 브라우저 직접 자동화 (`scripts/naver_bot.py`)**
   - Playwright 기반의 브라우저 UI 직접 제어 (외부 HTML 붙여넣기 시 서식 깨짐 문제 완벽 해결)
   - 마크다운 파싱 및 네이버 전용 정품 서식 주입:
     - 카테고리 자동 선택
     - 제목 및 문단 서식 소제목(30pt 볼드) 자동 적용
     - **인라인 형광펜/하이라이트** (`[HIGHLIGHT]...[/HIGHLIGHT]`)
     - **인라인 글자색** (`[COLOR:green/red/blue]...[/COLOR]`)
     - **형광펜 + 글자색 동시 적용** (`[HIGHLIGHT][COLOR:red]...[/COLOR][/HIGHLIGHT]`)
     - 원장님 지정 공식 여우 스티커 팩(`cafe_004`) 자동 삽입 & **중앙 정렬** (`[STICKER: greeting/cheering/like/clap/ok]`)
     - 정품 인용구 박스 컴포넌트 (`[QUOTE]...[/QUOTE]` 또는 `> ` 블록)
     - 정품 가로 구분선 컴포넌트 (`[DIVIDER]`)
     - 본문 사진/다이어그램/로고 자동 업로드 (`[IMAGE: 경로]`)
     - 해시태그 일괄 등록
   - **단일 초안 보장 & 중복 정리**: 기존 동일 제목의 이전 초안들을 자동 정리하여 블로그에 초안이 중복 누적되지 않고 항상 1개만 깔끔하게 [임시저장]
   - 불필요한 스크린샷 캡처 과정을 제거하여 빠르고 쾌적한 실행
   - 일반 브라우저 화면 모드 및 백그라운드 무화면 모드(`--headless`) 지원

3. **스마트에디터 ONE 사전 HTML 미리보기 (`미리보기.bat` / `scripts/generate_preview.py`)**
   - 임시저장 실행 전 브라우저에서 10초 만에 글의 흐름, 가독성, 서식 배치 점검
   - **데스크톱(720px) / 모바일(430px) 실시간 뷰포트 토글 지원**
   - 19pt 본문, 30pt 볼드 소제목, 여우 스티커 중앙 정렬, 인용구 박스, 이미지(대표 뱃지), 형광펜/글자색까지 네이버 에디터원과 100% 동일한 비주얼 렌더링
   - 더블클릭 한 번으로 기본 웹 브라우저 자동 실행 (`미리보기.bat`)

4. **`원고.md` 단일화 기반 애자일 퇴고 환경**
   - **`원고.md`**: 복잡한 파일 분리 없이 포스트당 단 1개의 완성형 마크다운 원고로 관리
   - 원장님은 70% 러프한 생각과 뼈대만 작성하시고, AI가 사진 배치(`[IMAGE]`), 여우 스티커, 형광펜, 소제목 서식을 즉시 결합
   - 퇴고 시에도 `원고.md` 하나만 수정하거나 대화창으로 편하게 요청하면 즉시 갱신
   - **`3_미리보기.html`**: `원고.md`를 기반으로 브라우저에서 모바일 가독성을 10초 만에 점검하는 완성형 뷰어

5. **원클릭 로그인 세션 보존 (`로그인하기.bat`)**
   - 최초 1회 브라우저 로그인을 자동 감지하여 쿠키 및 세션을 영구 보존 (`.naver_session/`)
   - 이후 매 포스팅마다 재로그인 없이 자동화 수행

```text
├── scripts/
│   ├── naver_bot.py                 # 스마트에디터 ONE 자동화 봇 (표준)
│   └── generate_preview.py          # 브라우저 사전 점검용 HTML 미리보기 생성기
├── 미리보기.bat                     # 브라우저에서 즉시 HTML 미리보기 열기
├── 임시저장하기.bat                 # 네이버 에디터원에 단일 임시저장 실행
├── 로그인하기.bat                   # 최초 1회 로그인 세션 등록용 스크립트
├── .gitignore
└── README.md
```

## 🚀 사용 방법

### 1. 사전 요구사항
- Python 3.10 이상
- Chrome 브라우저 설치

```bash
pip install playwright
playwright install chrome
```

### 2. 최초 1회 네이버 로그인
`로그인하기.bat`을 실행하거나 아래 명령어를 입력합니다:
```bash
python scripts/naver_bot.py login
```
열린 브라우저에서 네이버에 로그인하면 봇이 자동으로 감지하여 세션을 영구 저장합니다.

### 3. 에디터원 올리기 전 사전 점검 (HTML 미리보기)
`미리보기.bat`을 더블클릭하면 크롬/엣지 브라우저에서 즉시 열립니다:
- 바탕화면에서 **`미리보기.bat`** 더블클릭 (가장 최근 작업 중인 포스트 자동 오픈)
- 상단의 `📱 모바일 (430px)` 버튼을 눌러 스마트폰 화면 기준 10초 만에 가독성 점검

### 4. 블로그 원고 스마트에디터 ONE 단일 임시저장
검토가 끝난 원고를 네이버 에디터에 주입하고 단일 임시저장합니다:
- 바탕화면에서 **`임시저장하기.bat`** 더블클릭! (가장 최근 완성된 포스트 자동 주입)
- 또는 터미널 명령어로 수동 지정 실행:
  ```bash
  python scripts/naver_bot.py draft --file "output/2026-09-15_1편_안정적인_병원을_나와_리무브를_연_이유"
  ```
주입 완료 후 네이버 블로그의 **[저장]** 목록에서 작성된 글을 확인하고 편하게 [발행]하시면 됩니다.
