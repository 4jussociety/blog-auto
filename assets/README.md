# 📁 리무브 체형교정 공식 사진·에셋 카탈로그

'리무브 체형교정' 블로그 포스팅 작성 시 즉시 활용할 수 있도록 정리된 공식 이미지 에셋 보관소입니다.  
원고 작성 시 문맥에 맞는 이미지를 선택하여 `[IMAGE: images/파일명]` 또는 `[IMAGE: assets/폴더/파일명]` 형식으로 사용할 수 있습니다.

---

## 🗂️ 디렉터리 구성

```text
assets/
├── 로고/              # 브랜드 공식 로고 및 심볼 (고화질, 원형, 배너)
├── 프로필/            # 대표 원장 면허·이력 카드 및 네임 그래픽 (텍스트 검색 방지용)
├── 리뷰/              # 실제 회원 후기 캡처본 (개인정보/병원명 마스킹 완료)
│   └── 원본/          # 마스킹 전 원본 스크린샷 보관
├── 에디터참조/        # 네이버 스마트에디터 ONE 자동화 개발/UI 규격 참조용 스크린샷
├── posts/             # 최종 확정된 완성형 원고(태그 포함) 누적 아카이브
├── 센터 정보.txt      # 상호명, 주소, 슬로건 기본 정보
└── README.md          # [현재 문서] 전체 사진 자료 카탈로그 & 활용 매칭표
```

## 5. 📚 포스트 아카이브 (`assets/posts/`)

블로그에 최종 발행되거나 임시저장된 **완성형 마크다운 원고(`원고.md`)**가 태그(스티커, 인용구, 형광펜, 사진 태그)를 온전히 보존한 채 누적 보관되는 폴더입니다.

- `01편_안정적인_병원을_나와_리무브를_연_이유.md`
- `02편_병원시절_환자분들이_저를_지명했던_5가지_이유.md`
- ...

> **아카이빙의 목적**:  
> 향후 3편, 4편 등 새로운 포스트를 기획할 때 AI가 누적 원고 전체를 정독하여 **원장님의 문체(어조, 비유법)뿐만 아니라 비주얼 리듬(스티커/형광펜/사진 배치 주기)까지 완벽하게 계승**합니다.
